# Train Recruits (Forge 1.20.1)

Сабмод, що «дружить» **Recruits** (+ Recruits: Living Villages) із **Create** (потяги).
Командир (Commander) і його загін самі підходять до зупиненого потяга, сідають на Create-сидіння
(«пуфики»), а на станції призначення — виходять.

## Блоки
| Блок | Що робить |
|---|---|
| **Станція посадки** (Boarding Station) | Кличе ваших рекрутів + командирів (і весь їхній загін) на вільні місця зупиненого потяга поруч (радіус `trainRadius`, 12 блоків). |
| **Станція висадки** (Disembark Station) | Висаджує ваших рекрутів із потяга біля блока: ставить на платформу поруч і дає команду «стояти» (HOLD). |

Рецепти: рамка з 4 залізних зливків і 4 рейок, у центрі смарагд (посадка) / редстоун (висадка).

## Як керувати (кнопки)
* **ПКМ по блоку** — дати команду зараз (посадка / висадка).
* **Редстоун-сигнал** (кнопка, важіль, Create-датчик, станція потяга…) — команда по фронту сигналу.
* **Shift + ПКМ** — перемкнути **авто-режим**:
  * посадка: щойно поруч зупиниться потяг із вільними місцями — загін іде сідати;
  * висадка: щойно потяг зупинився біля станції — всі ваші пасажири виходять.
* Блок прив'язується до гравця, що його поставив. Чужий загін не чіпає.

## Командири (Жезл командира)
Жезл — вкладка «Інструменти» (рецепт: золотий злиток + 2 палиці по діагоналі).
* **ПКМ жезлом по своєму рекруту** (будь-який тип) — він стає командиром за **2× ціни найму** (у валюті Recruits; у творчому безкоштовно). Ім'я з префіксом `[C]`.
* **ПКМ жезлом по командиру** — розжалувати (загін розформовується, гроші не повертаються).
* Множник ціни: `config/trainrecruits-common.toml` → `costMultiplier`.
* **Загін ніколи не збирається автоматично.** Нових найнятих юнітів до жодного командира не прив'язує.

## Власна карта (клавіша N, змінюється в Керуванні → Train Recruits)
Проста тактична карта: рельєф (запам'ятовує те, що ви бачили), ваші станції (**B** посадка, **D** висадка, жовта цятка — авто), загони командирів (**C** синій; фіолетовий — їде в потязі), ви (зелена точка).
* Клік по загону або станції — вибрати. Тяг мишею — рухати карту, колесо — масштаб.
* **Вибрали загін → клік по землі** — командир іде туди, весь загін строєм за ним.
* Кнопки знизу: «До мене», «Загін: стояти», «Загін: за мною», «Посадка/Висадка» (вибрана станція), «Авто».
* Працює з будь-якої відстані, але командир/станція мають бути в завантажених чанках.
* Карта Recruits (M) лишається окремо — для держав і кордонів.

## Типовий сценарій
1. Біля платформи ставите **Станцію посадки**, потяг із сидіннями Create стоїть поруч.
2. ПКМ (або редстоун) → командир та загін підходять і сідають (командир переходить у стан PAUSED, щоб не тягнув загін патрулювати).
3. Відправляєте потяг своїми механізмами.
4. На кінцевій біля **Станції висадки** (авто-режим або ПКМ/редстоун) — всі виходять на платформу.

## Налаштування
`config/trainrecruits-common.toml`: радіуси, час очікування, чи треба щоб потяг стояв,
що робити після висадки (`HOLD` / `FOLLOW` / `WANDER`), чи відновлювати патруль командира.

## Збірка на GitHub Actions
1. Завантажте **весь** вміст цієї папки в репозиторій (включно з `libs/` — там jar-и Create, Recruits, Villages; вони потрібні лише для компіляції).
2. Вкладка **Actions → Build mod → Run workflow** (або просто push).
3. Готовий jar: у результаті запуску, секція **Artifacts → trainrecruits-jar**.
4. Кладете jar у `mods/` разом із Create 6.0.8, Recruits 1.15.2 (і Villages, якщо потрібен).

Імена файлів у `libs/` мають бути саме такі: `create-1.20.1-6.0.8.jar`, `recruits-1.20.1-1.15.2.jar`
(формат `<назва>-<версія>.jar` вимагає Gradle). Якщо оновите версії — змініть їх у `build.gradle`.

## Артилерійські розрахунки (Create Big Cannons)
Для цього потрібні **Create Big Cannons** (5.x) і **Recruits Villages**; обидва необов'язкові для решти мода.
* **Мобілізація:** жезл командира, ПКМ по **звичайному жителю** з рекрутерського поселення **вашої** фракції. Повторно, щоб розпустити. Ціна: `artillery.gunnerCost` (за замовчуванням 0).
* **Гармату будуєте ви** (cannon mount + ствол, зібрана). Розрахунок сам знаходить найближчу працюючу гармату в радіусі `bindRadius` (24), підходить до неї й керує нею.
* **Снаряди безкінечні:** гармату не треба заряджати. Розрахунок сам наводить стовбур (рахує балістику з гравітацією й опором, воліє пологу траєкторію, якщо вона вільна від рельєфу, інакше навісну) і стріляє снарядом `createbigcannons:he_shell` з дула.
* **На карті (N)** розрахунок це **фіолетовий ромб «A»**. Клікніть на нього, потім на точку на землі: розрахунок вистрілить `shotsPerOrder` (3) разів з паузою `reloadSeconds` (12). Кнопки «Розрахунок: авто» і «Розрахунок: стоп».
* **Автоцілі** (якщо не відключено): села фракцій, що воюють з вами (або вороги в дипломатії), гнізда зараження Flesh That Hates, поселення Barbarian Raids. Не стріляє, якщо біля точки влучання (`friendlyClearance`, 24) є гравець, ваші рекрути чи жителі вашої фракції.
* Дальність: `minRange` 20 – `maxRange` 200. Усе налаштовується в секції `artillery` у `trainrecruits-common.toml`.
* Зв'язок із Big Cannons і Recruits Villages іде через рефлексію (без залежності при збірці). Якщо щось не працює, дивіться в лог рядки `[artillery]`.

## Артилерія сіл
Села (не фракції гравців), у яких населення (воїни + жителі) досягло `villageArtillery.minPopulation` (12), самі будують просту гармату Create Big Cannons (кріплення + бронзовий казенник, камора, два стовбури), збирають її й садять розрахунком жителя свого села. Такий розрахунок стріляє за тими самими правилами (ворожі за війною/дипломатією села, гнізда зараження, варварські поселення), без власника-гравця; повтор спроби `retryMinutes`. Налаштування: секція `villageArtillery`.

Дебаг-тул «Artillery Debug Tool» (творчий режим, вкладка інструментів): ПКМ по землі — одразу з'являється гармата в бік, куди ти дивишся, і на неї сідає найближчий житель села (якщо жителя нема — створюється житель найближчого села).
